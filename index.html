    Workshops and Trainings Factory

    WTFactory is where the UiPath Partner Success team builds and runs its hands-on workshops. This is the catalog. Each course is a participant handbook on its own site; each exercise is a complete business case with the environment prepared for you.

    Agentic Automation Workshop (Agentic Practice)

    Hands-on introduction to UiPath agentic automation for people practising for the first time — three exercises, each a complete business case.

    Audience: workshop participants new to agents; no developer background required

    Exercise What you build Level Products Before you start
    Categorizing ServiceNow Incidents Build a low-code agent that triages IT incidents with tools, context grounding, an escalation app and agent memory. 100 Agents (low-code), Context Grounding, Action Center, Integration Service
    Conversational Agents Build a multi-turn conversational agent that reuses the incident tools. 100 Conversational Agents, Agents (low-code) Categorizing ServiceNow Incidents
    Two-Way Matching of Invoices and Purchase Orders Orchestrate a Maestro BPMN process with IXP extraction, a low-code matching agent and a human validation app. 200 Maestro BPMN, IXP, Agents (low-code), Action Center, Orchestrator Categorizing ServiceNow Incidents

    UiPath Coding Agents Workshop

    Build UiPath agents and Maestro orchestrations with a coding agent and the uip CLI — from installing the tools to shipping an end-to-end solution.

    Audience: technical clients and partners who know the UiPath platform and are new to AI coding agents

    Exercise What you build Level Products Before you start
    Build Your First Agent Build a low-code Claims Eligibility agent from two PDFs with a coding agent, give it an evaluation set, and run a test-and-fix loop from the CLI. 100 Agents (low-code), Agent Evals, uip CLI & skills Getting Started with Coding Agents
    Getting Started with Coding Agents Install the uip CLI and the UiPath skills, authenticate, and practise the platform read commands before the first build. 100 uip CLI & skills
    Loan Application Underwriting An AI underwriting agent, a loan-officer review app, a Maestro Flow orchestration and an RPA intake step, built with a coding agent. 200 Agents (coded), Coded Apps, Maestro Flow, RPA, uip CLI & skills Getting Started with Coding Agents
    A Simple Maestro BPMN Process with a Coding Agent Model and deploy a small BPMN process in Maestro by driving a coding agent — a standalone exercise between the first agent and the end-to-end builds. 100 Maestro BPMN, uip CLI & skills Build Your First Agent
